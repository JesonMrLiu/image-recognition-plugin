# 通用图片描述

适合只需要"看懂图里有什么"的通用场景（截图说明、图表解读、故障截图分析等）。

## prompt 模板（按需二选一）

### A. 完整描述
```
请用中文详细描述这张图片：
- 图片类型（截图 / 照片 / 图表 / 设计稿 / 示意图）
- 主体内容与布局
- 所有可见的文字（原样提取，含中文/英文/数字）
- 颜色、风格、显著细节
不要编造图中没有的内容；看不清的部分标注"（不清晰）"。
```

### B. 报错/故障截图分析
```
这是一张报错/故障截图。请：
1. 原样提取所有错误信息、堆栈、错误码
2. 指出可能出错的模块/文件/接口
3. 给出 3 条最可能的排查方向（按可能性排序）
```

## 调用示例

```json
{
  "image": "clipboard",
  "prompt": "<模板 A 或 B>",
  "detail": "high"
}
```

## 提示

- 含大量小字时务必用 `detail: "high"`。
- 剪贴板输入前，请先让用户用截图工具复制图片到剪贴板（Windows: Win+Shift+S）。
