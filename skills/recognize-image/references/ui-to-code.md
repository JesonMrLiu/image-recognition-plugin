# UI 稿 / 截图 → 前端代码

适合把一张界面截图转成可运行的前端组件代码。

## prompt 模板

```
你是一名资深前端工程师。请仔细分析这张界面截图，按以下要求产出代码：

1. 整体布局结构（从外到内的容器层级、flex/grid 方案、响应式断点）
2. 列出可见的组件及其层级（导航 / 侧边栏 / 卡片 / 表单 / 按钮等），给出合理的组件拆分
3. 配色与字号体系（主色、辅助色、背景、文字大小、圆角、阴影），用 CSS 变量表达
4. 关键交互元素（按钮、输入框、下拉、tab、开关）及它们的可访问性属性
5. 文案请原样提取（不要自己编）

技术栈：<在此填：React + TypeScript + TailwindCSS / Vue3 + Element Plus / ...>
组件库：<在此填：antd / shadcn-ui / 自研 / 无>

最后输出：
- 一个可直接使用的单文件组件代码
- 一段"实现说明"，列出你做了哪些取舍、哪些地方因截图不清晰需要再确认
```

## 调用示例（recognize_image）

```json
{
  "image": "D:/proto/dashboard.png",
  "prompt": "<上面的模板，技术栈填 React + TypeScript + TailwindCSS>",
  "detail": "high",
  "max_tokens": 4096
}
```

## 提示

- 截图越完整越好；只截局部时在 prompt 里说明"这是 XXX 页面的主体区域"。
- `detail: "high"` 对含文字/图标的 UI 稿识别更准。
- 涉及图标时，让模型用占位或现有图标库名，不要凭空编 SVG 路径。
